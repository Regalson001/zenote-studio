# ✦ Zenote Studio — Premium Notes & Productivity Workspace

**Capture ideas. Organize thoughts. Get things done.**

Zenote Studio is a modern, responsive notes management application designed to provide a clean, elegant, and productive writing experience. Built with HTML5, CSS3, and Vanilla JavaScript, it allows users to create, edit, organize, search, and manage personal notes through an intuitive workspace.

The application combines a premium SaaS-inspired interface with practical productivity features, including automatic local saving, folders, favorites, pinned notes, tags, dark mode, and JSON backup functionality.

## ✨ Key Features

### 📝 Note Management
- Create unlimited notes, subject to browser storage capacity.
- Edit note titles and content.
- Automatically save changes.
- Delete notes and move them into the trash.
- Restore notes from the trash.
- Permanently delete unwanted notes.

### 📁 Organization & Productivity
- Create custom folders.
- Organize notes by category.
- Pin important notes.
- Mark notes as favorites.

- Add and remove custom tags.

### 🔍 Search & Navigation
- Search notes by title.
- Search note content.
- Search folders and tags.
- Navigate between workspace sections.
- Sort notes by recently edited, creation date, and alphabetical order.

### 🎨 Modern User Interface
- Premium SaaS-inspired dashboard.
- Clean sidebar navigation.
- Modern note cards.
- Dedicated note editor.
- Responsive grid and list layouts.
- Light and dark themes.
- Smooth transitions and interactive elements.

- Text formatting toolbar.
- Bold and italic Markdown-style formatting.
- Heading insertion.

## 💾 Data Storage & Privacy

Zenote Studio currently uses the browser's Local Storage API to save notes.

This means:

- Notes remain available after refreshing the page.
- Data is stored locally in the browser.
- No backend server or user account is required.
- Export functionality allows users to create JSON backups.

**Important:** Local Storage is specific to the browser and device. Clearing browser data may remove saved notes. Export backups regularly to protect important information.
